# Web TV Remote

[English version](README.md)

Пульт для Android-приставки или проектора в браузере любого телефона, планшета или компьютера
в домашней сети. На телефон ничего ставить не нужно: открыли ссылку, ввели PIN — готово.

- Работает на самой приставке (Android 11+, Android TV или обычный Android).
- Встроенный веб-сервер, доступный с любого устройства в локальной сети.
- PIN-код при первом подключении браузера.
- Автозапуск при включении приставки / проектора.
- При запуске приложение на ТВ показывает ссылку и QR-код для телефона.
- Только тёмная тема, интерфейс под телефон, можно добавить на экран «Домой».

Раскладка пульта: сверху «выключить», «клавиатура», «настройки»; крупная крестовина с «OK»;
«назад», «домой», «опции»; «тише» / «громче»; внизу — настраиваемая горизонтальная лента приложений.

## Как это работает

Обычное Android-приложение не может отправлять нажатия клавиш (крестовина, «Меню», «Питание»)
другим приложениям. Поэтому Web TV Remote подключается к **собственному** ADB приставки через
`127.0.0.1:5555` («Отладка по сети») и запускает маленький вспомогательный процесс от имени
пользователя `shell` — так же, как это делает scrcpy. Он вводит нажатия напрямую в систему ввода,
без задержек. Данные не покидают устройство, компьютер не нужен.

Без ADB пульт работает в ограниченном режиме: «Назад», «Домой», громкость, запуск приложений,
клавиатура (со службой спец. возможностей), а на Android 13+ ещё и крестовина.

## Установка

1. Скачайте `web-tv-remote.apk` из [Releases](../../releases) (или артефакт последней сборки CI).
2. Установите на приставку — с флешки через файловый менеджер или `adb install web-tv-remote.apk`.
3. **Один раз откройте** Web TV Remote на приставке: Android не запускает приложение при загрузке,
   пока его ни разу не открывали.

### Включите ADB (рекомендуется, нужно для крестовины и всех кнопок)

1. Настройки → Настройки устройства → Об устройстве → 7 раз нажмите **Сборка** — откроется
   раздел «Для разработчиков».
2. Настройки → Настройки устройства → Для разработчиков → включите **Отладку по USB** и
   **Отладку по сети** / **ADB по сети** (название зависит от производителя).
3. Вернитесь в Web TV Remote. Появится запрос **«Разрешить отладку?»** — отметьте
   **«Всегда разрешать с этого компьютера»** и подтвердите обычным пультом. Это нужно один раз.

Строка статуса на ТВ сменится на «полное, через ADB». Приложение само повторяет подключение и
делает это сразу при каждом открытии — после включения «Отладки по сети» просто вернитесь в него. Через ADB приложение само выдаёт себе
разрешение «поверх других окон» (для показа PIN) и отключает для себя оптимизацию батареи.

> **Нет переключателя «Отладка по сети»?** На некоторых приставках есть только *Беспроводная
> отладка* Android 11+ (код сопряжения, случайный порт) — она пока не поддерживается. Подключите
> приставку к компьютеру один раз и выполните `adb tcpip 5555`; на многих устройствах также нужно
> `adb shell setprop persist.adb.tcp.port 5555` (если разрешено), чтобы порт сохранялся после перезагрузки.

### Служба спец. возможностей (необязательно)

Позволяет вводить текст на любом языке (в том числе кириллицу) прямо в активное поле, а также
«Назад»/«Домой» без ADB. При подключённом ADB приложение включает службу само, один раз — если
потом выключить её вручную, она останется выключенной. Без ADB есть кнопка **Спец. возможности** на экране ТВ.

## Использование

1. Откройте Web TV Remote на приставке — там ссылка вида `http://proektor-v-zale.local:8080` и QR-код
   с ней (IP-адрес показывается, только пока имя ещё не объявлено в сети).
2. Откройте ссылку на телефоне (отсканируйте QR-код).
3. На ТВ поверх изображения появится 4-значный PIN — введите его. Браузер запоминается,
   больше PIN не спрашивается.

| Кнопка | Нажатие | Удержание |
| --- | --- | --- |
| Крестовина | перемещение | повтор |
| OK, Назад, Домой | нажатие | долгое нажатие (контекстное меню, недавние приложения) |
| Громкость −/+ | шаг | повтор |
| Ползунок громкости | задаёт громкость приставки напрямую (скрыт, если у приставки фиксированная громкость по HDMI) | |
| Выключить | «Питание» (сон) | |
| Клавиатура | поле ввода, зеркалируемое на ТВ; работают Ввод и Стереть | |
| Настройки | открывает настройки приставки | |
| Приложения | запуск; «Изменить» — добавить, убрать, поменять порядок (хранится на приставке, общий для всех телефонов) | |

На компьютере работает клавиатура: стрелки, Enter = OK, Esc/Backspace = Назад, Home, `+`/`-` — громкость.

### Добавить на экран «Домой»

- **iPhone / iPad (Safari):** Поделиться → *На экран «Домой»*. Открывается на весь экран, как приложение.
- **Android (Chrome):** ⋮ → *Добавить на главный экран*. Полноценную установку (без адресной строки)
  браузеры разрешают только для HTTPS. Для локального адреса откройте
  `chrome://flags/#unsafely-treat-insecure-origin-as-secure`, добавьте адрес пульта
  (например `http://192.168.1.50:8080`), включите, перезапустите Chrome и выберите *Установить приложение*.

### Постоянный адрес (`<имя-устройства>.local`)

Приставка объявляет себя в сети через mDNS под именем, составленным из названия устройства (Настройки →
Настройки устройства → Об устройстве → Название): «Проектор в зале» превращается в
**`http://proektor-v-zale.local:8080`**, а если ничего не осталось — `tv-remote.local`. Если имя в сети уже
занято, приставка берёт `-2`, `-3`… и запоминает его, так что две одинаковые приставки не меняются адресами.
Текущее имя показано на экране ТВ. В отличие от IP, этот адрес не меняется — его и стоит сохранять в
закладки и на экран «Домой». Его понимают iPhone/iPad, macOS, Windows и Linux (avahi); на Android-телефонах —
в зависимости от версии Android и браузера. Если пульт открыт по IP на устройстве, которое понимает это имя,
он сам предложит перейти на постоянный адрес. Для браузера это другой сайт, поэтому PIN спросят ещё раз.

Другой вариант — закрепить за приставкой постоянный IP в роутере.

## Безопасность

- Любой запрос к API требует сопряжённого браузера. Для сопряжения нужен PIN с экрана ТВ.
- PIN случайный, живёт 3 минуты и меняется после 5 неверных попыток; каждая ошибка замедлена на секунду.
- После сопряжения браузер получает случайный 256-битный токен в cookie `HttpOnly`, `SameSite=Strict`;
  на приставке хранится только его SHA-256. Кнопка **Забыть устройства** отзывает все токены.
- Запросы с доменным именем в `Host` (кроме `localhost`/`*.local`) отклоняются — защита от DNS rebinding.
- ADB подключается только к `127.0.0.1`; вспомогательный процесс слушает `127.0.0.1` и требует токен.
- Трафик — обычный HTTP внутри домашней сети. Не открывайте порт в интернет.
